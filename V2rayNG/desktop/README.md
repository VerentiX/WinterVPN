# Lampa VPN Desktop

Windows-клиент, повторяющий простой сценарий мобильной Lampa: подписка → сервер → одна кнопка подключения.

## Возможности

- импорт той же subscription URL, что используется на Android, включая полный JSON-автоконфиг `/auto/`;
- запрос подписки с `User-Agent: Lampa-Desktop/1.0` и получение двух Roscom routing-профилей (`p0-p4` Full, `p5+` Whitelist);
- управляемый автоконфиг с готовыми outbound, routing и balancer сохраняется целиком; обычные VLESS, VMess и Trojan ссылки также поддерживаются;
- TUN включён по умолчанию: весь IPv4/IPv6 TCP/UDP-трафик направляется через виртуальный интерфейс Lampa;
- раздельное туннелирование по Windows-приложениям: выбранные `.exe` идут напрямую;
- локальные HTTP/SOCKS прокси доступны как запасной режим;
- сворачивание в трей и автозапуск;
- watchdog для перезапуска упавшего `xray.exe`;
- восстановление после сна/гибернации и смены сети с ожиданием доступного интерфейса;
- сохранение намерения пользователя: если VPN был включён до сна или перезапуска приложения, он включится снова.

## Сборка

```powershell
dotnet build .\desktop\Lampa.Desktop\Lampa.Desktop.csproj -c Release
```

Для отдельной разработки desktop-части используйте solution `desktop/Lampa.Desktop.slnx`:

```powershell
dotnet build .\desktop\Lampa.Desktop.slnx -c Debug
```

Windows x64 Xray Core, `geoip.dat`, `geosite.dat` и Wintun входят в сборку и автоматически копируются в папку `core` рядом с приложением. Пользователю не требуется отдельно скачивать или настраивать core.

Приложение запрашивает права администратора, необходимые Windows для создания TUN-интерфейса и автоматической установки маршрутов. При отключении или штатном завершении Xray удаляет интерфейс и созданные им маршруты.
